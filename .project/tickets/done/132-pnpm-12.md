# 132 — Upgrade to pnpm 12 and drop Node from the Docker builder

**Status:** done

## Goal

Move the repo from pnpm 9.15.4 to pnpm 12 (`12.23.0`, the `latest-12` tag). pnpm 12 is a native executable that runs without Node.js once installed. The Docker builder then no longer needs a Node runtime to install dependencies, which removes the `Unsupported engine ... v20.11.1` warning from ticket 131 without a Node 24 base image.

## Depends on

- Ticket 94 (Node 24 floor for the repo's own tooling and CI)
- Ticket 59 / 62 (Dockerfile and Cloudflare container image)
- Supersedes ticket 131, whose Node 24 builder approach is replaced by this one.

## Done when

- [x] `package.json` `packageManager` is `pnpm@12.23.0`
- [x] `.github/workflows/ci.yml` and `deploy-cloudflare.yml` use `pnpm/action-setup` with `version: 12.23.0`
- [x] `pnpm install --frozen-lockfile` passes under pnpm 12
- [x] Dependency build scripts for `esbuild`, `msgpackr-extract`, and `workerd` are approved in `pnpm-workspace.yaml` (`allowBuilds`). pnpm 12 blocks dependency build scripts by default.
- [x] Dockerfile builder stays on `oven/bun:1.4`. pnpm 12 is installed with the standalone script (`PNPM_VERSION=12.23.0`). No Node in the builder.
- [x] `docker build` completes with no `Unsupported engine` warning and no `Proceed?` prompt
- [x] Runtime image starts and `GET /healthz` returns `{"ok":true}`
- [x] `bun run ci` passes under pnpm 12 (forced run, 9/9 tasks, 725 tests)

## Notes

- pnpm 12 writes its own platform binaries into `pnpm-lock.yaml` (`packageManagerDependencies`, `@pnpm/exe.*`). The rest of the lockfile is unchanged.
- pnpm 12 reports `ai` and `skills` as awaiting build approval. Neither needs an install script for this repo's builds, and the tests pass.
- Node is still used by the repo's own tooling: `engines.node >=24` and the CI `setup-node` 24 step. The image runs those tools through Bun's `node` shim. This ticket does not remove Node from the repo's developer or CI setup.
- pnpm 12 reads the same `pnpm-lock.yaml` and `pnpm-workspace.yaml` format as pnpm 11.
